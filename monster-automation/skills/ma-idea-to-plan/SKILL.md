# Идея → план

Это ярлык, а не локальная копия сценария. При каждом запуске:

1. Перед любыми действиями вызови через Monster Automation MCP `ma_get_context` с `pluginVersion: "1.1.3"` — это версия данного ярлыка, не Cursor. Не подменяй её последней версией с сервера. Повторяй запрос при каждом запуске, не используй прошлый ответ.
   Проверь `cursorPlugin`: только `current` + `canRun: true` разрешает продолжить молча; `update_available` + `canRun: true` — кратко показать текущую и последнюю версии, `releaseNotes`, `accessPageUrl` и продолжить.
   Во всех остальных случаях (включая `update_required`, `unknown`, отсутствующие поля и ошибку запроса) ОСТАНОВИСЬ до загрузки сценария. Объясни причину и предложи обновить плагин: Customize → Plugins → + Add → From GitHub → https://github.com/tecor-dev/plugin, затем Plugins → Configure с ключом из кабинета. Либо скачайте пакет из кабинета https://app.monster-automation.com/agency/mcp-access и `node install.mjs --update`. Если сервер не отдаёт проверку, попроси администратора обновить MCP. Не обновляй файлы автоматически, не проси ключ в чат и не читай файлы с ключами.
2. Вызови `ma_get_playbook` с `name: "ma_idea_to_plan"` и передай уточнения пользователя после команды строкой `input`, если они есть. Получи полный текст заново, не используй версию из памяти или предыдущего запуска. Покажи возвращённые `contentVersion` и `updatedAt`.
3. Прочитай и выполни полученный сценарий. Перед соответствующей фазой прочитай связанные ресурсы `ma://` через MCP. Для стандартов и шаблонов допустимы `ma_get_standard` и `ma_get_template`. При недоступном обязательном ресурсе останови эту фазу, не выдумывай его содержимое.
4. Перед проектными действиями определи доступный проект через `ma_resolve_project` по Git remote, не передавая учётные данные из URL. При неоднозначности предложи человеку выбрать из `ma_list_projects`. Соблюдай явный выбор пользователя; не угадывай `projectId`.
5. Запуск команды не расширяет полномочия. Перед push, production-деплоем, завершением задач и отправкой сообщения клиенту получи явное подтверждение соответствующего действия. Не устанавливай `humanConfirmed: true` без такого подтверждения. Внешние skills не входят в пакет: если нужного skill нет, назови зависимость и останови только зависимую фазу; не устанавливай её без согласия.
